# Profile decision and production handoff

17 October 2026. Independent source/evidence review17 and visual review18 are complete.

The signed carrier produces visibly narrower separated bands and gaps at fixed native states, replacing the original broad positive coverage patch. All8 decoded parity/null/repeat gates pass; shader/control identities match. This supports carrying signed phase structure forward. It does not establish continuous relief, smooth phase motion, physical-fluid behavior or reference reconstruction.

The old point transfer makes negative lobes shrink/disappear. Thus the gaps cannot be read as faithful signed heights. The production direction is an explicit continuous shaded-mesh extension with a signed radial packet and analytic gradients, following SURFACE-DELIVERY.md and the existing SurfaceFactory contract. No stateful solver or object is justified/introduced by these studies.

Stage1's weak frozen slope-to-tone patch is not being adopted or contrast-retuned. The new renderer must derive height and normals consistently, handle the center/cap and lifecycle correctly, and pass actual integrated visual/interaction review before the active goal can be complete. The calmer production speed and material coefficients are recorded as new delivery decisions, not as one-variable study conclusions.
