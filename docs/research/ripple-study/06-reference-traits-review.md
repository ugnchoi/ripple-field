# Stage 0 reference-traits review rubric

17 October 2026 · Existing evidence only · No new capture, browsing, application edits or candidate selection.

Use this rubric to describe which reference traits are visible in the four baseline conditions and which layer contributes them. Stage 0 isolates ambient and automatic-event contributions; it does not test a replacement water model or a dithering algorithm. A condition can reveal a useful trait without resembling the complete reference.

## Five-trait rubric

Use **N/A** where the study lacks the required subject or context. These labels describe evidence; they are not quality grades and must not be added into a resemblance score. Confidence below concerns the reference observation, not confidence that a study will reproduce it.

## Applying it to Stage 0

1. Confirm the coordinator's reproducibility record first: same seed/geometry, event scenario, fixed times, dimensions, actual DPR and polish off. Use field-only captures to inspect motion and texture, then unchanged Resume context to inspect hierarchy. A mismatch in these controls makes a layer attribution inconclusive.
2. Review the same scripted scenario/time pairs in all four conditions. Compare ambient off/on with auto held fixed, then auto off/on with ambient held fixed. Report whether a trait becomes clearer, is masked or cannot be distinguished. Changing both factors at once does not isolate their contributions.
3. Keep scenario meaning explicit. Multiple fronts after simultaneous/delayed impulses are a local stimulus result; the passive reel supplies no corresponding input tape. Idle or no-event behavior is valuable baseline evidence even when it has no close reference counterpart. Do not call automatic spontaneous events “the reference interaction.”
4. Record desktop and mobile separately. Reference-native coordinates support the observation, not a pixel-level target for a 1440 × 900 or 390 × 844 study. If a normalized displacement or crop comparison is used, state the coordinate normalization and region; aspect ratio, projection, tonal polarity and point density remain confounds.
5. Use a compact review row: **condition · scenario/time pair · output/DPR · trait label · evidence path · observed layer effect · alternative/limitation**. Describe readability and visual resemblance separately. Do not declare a winner, retune parameters, infer a fluid solver or select a dither method from these labels.

## Decision supported and decision deferred

This rubric supports a bounded conclusion such as: “Ambient adds visible long contours, while the automatic event tape adds local fronts; together they obscure the tracked band in this crop.” That statement requires paired study evidence and is not a finding of this reference-only review.

Stage 0 can establish which existing layers supply coherent motion, spatial variation and readable point structure, and whether the optional foreground remains visually stable. It cannot establish original implementation provenance, physical realism, reference interactivity, real-device performance, a seamless source loop, or measured reading success. After the controlled review, the coordinator can decide whether a later field or transfer-function experiment is justified. The reference alone does not decide that question.
