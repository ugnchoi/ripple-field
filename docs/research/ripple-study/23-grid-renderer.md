API `setScenario` restores tape/time0 and pauses; `setTime` pauses/evaluates synchronously; `setMode` only changes expression; replay resets selected tape and plays; clear removes sources at current time while retaining ambient. Canvas-only captures avoid DOM control occlusion. Coordinator owns native desktop/mobile A/B/C images, actual playback and direction assessment under `output/playwright/grid-reflections/`.
